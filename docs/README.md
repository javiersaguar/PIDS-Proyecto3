# Documentación del proyecto

## Qué hay que hacer

- Consultar el enunciado para comprobar los requisitos de evaluación y entrega.
- Mantener el plan y la lista de tareas al día. Registrar el responsable y el estado al empezar una tarea y enlazar el commit o la PR al completarla.
- Documentar los supuestos y las fuentes de datos de forma que se pueda justificar y reproducir el análisis.

## Qué debe incluir

- [enunciado.md](enunciado.md) recoge los requisitos, las especificaciones técnicas y la entrega.
- [datos.md](datos.md) contiene el diccionario, la procedencia y las comprobaciones de calidad.
- [PLAN.md](PLAN.md) organiza las fases, los métodos previstos y los hitos.
- [TAREAS.md](TAREAS.md) hace el seguimiento del trabajo y distingue requisitos de ampliaciones.
